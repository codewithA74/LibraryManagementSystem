# 📚 Library Management System

A command-line Java application to manage a library's book inventory.
Built as **Project 1** during the **Syntecxhub Internship Program**.

## Features
- Add, remove, and search books
- Borrow and return system
- Persistent storage using file handling (books.txt)
- Input validation and error handling

## Tech Stack
- Java (Core)
- File I/O
- IntelliJ IDEA

## How to Run
1. Clone the repo
2. Open in IntelliJ IDEA
3. Run `Main.java`

## Project Structure
src/
├── Main.java        # Entry point & menu
├── Library.java     # Core logic
├── Book.java        # Book model
└── FileHandler.java # File read/write
